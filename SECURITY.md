# Security Policy

This is an independent fork of xAI's Grok Build and is not affiliated with
or supported by xAI/SpaceXAI.

- For a vulnerability specific to this fork's own changes, please open a
  private [GitHub security advisory](https://github.com/nairsh/grok-build/security/advisories/new)
  on this repository rather than a public issue.
- For a vulnerability in the underlying, unmodified Grok Build code inherited
  from upstream, please report it to xAI's own program instead, since only
  they can fix it there: https://hackerone.com/x
